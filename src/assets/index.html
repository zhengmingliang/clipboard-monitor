详情

点一条日志查看内容、来源和格式。

每行一条。可以写进程名、可执行文件名或 WM_CLASS（Linux/X11），也可以写进程号。多个程序都叫 python3 时，用 pid:进程号 或单独一行数字，只排除这一个进程。进程重启后 PID 会变，需要重新填。监控进程自身始终排除。白名单在 Windows、macOS、Linux 上都生效：命中的程序内容不会写入数据库。

按时间范围和内容类型删除日志。至少要填一个条件。先预览再删除。


PRIMARY 是「选中文字即写入、中键粘贴即读取」的选择区；开启后每次拖动选中都会连续产生写入与读取记录，普通使用建议保持关闭。默认关闭，旧配置若已开启请在此取消勾选并保存。

这是什么

它记录本机剪贴板的文本与图片变化，日志留在本地 SQLite，不上传。Linux/X11 支持来源进程、PRIMARY 选择区和读取审计；Linux/Wayland 通过 ext-data-control 记录内容变化，但没有读取审计与来源进程归属。

平台差异

Windows 使用 WM_CLIPBOARDUPDATE 通知 + 序号预检；macOS 用 changeCount 快速路径并以最多每 2 秒的内容摘要采样兜底；Linux 使用 XFixes/RECORD，只有它能可靠审计读取。

Windows 的「推断读取」：Win32 在读取粘贴时不发任何通知。本程序用「其它进程打开剪贴板且序号未变」的轮询 + Ctrl+V 低级键盘钩子交叉推断，事件标为 reason=inferred_read、摘要里带判定依据。它是尽力而为的估计：菜单粘贴、极短读取可能漏掉，剪贴板管理器同步也可能被算作读取，不等价于可靠的全局读取审计。macOS 不产生读取事件。

记录规则

  • 纯文本、富文本：小于 1MB（可改）保存原文，达到上限只留大小和开头一段。
  • 文件列表：保存数量、名称和路径。只有勾选“保存单个小文件内容”且文件小于 2MB 时才读文件内容。
  • 图片和其它二进制：只保存格式、尺寸和大小，不保存像素。
  • 打开一条写入，流转里列出之后读过这份内容的进程。点其中一条会打开对应记录。

加密与搜索

剪贴板正文（文本、图片、元数据、摘要）用 AES-256-GCM 加密后落库，密钥由 Windows DPAPI / macOS Keychain / Linux 数据目录里的 0600 文件保管。时间、类型、应用名等列仍明文以便筛选。备份数据目录时必须连同密钥一起复制，否则数据库无法解密。搜索框由 FTS5 全文索引驱动，支持中文子串；索引的是解密后的明文，密文不会写进索引。

怎么停

页面上的开关只暂停记录，进程还在。命令行 clipboard-monitor stop 会退出进程。

限制

图片只保存格式、尺寸和大小，不保存像素。Linux 原生 Wayland 客户端不在当前 X11 后端能力范围内；macOS 每 200ms 检查启停状态、最多每 2 秒做一次内容摘要采样，Windows 由系统消息触发。macOS 14+ 的隐私提示可能要求用户允许本程序访问剪贴板。
